# KVN Muhurtham Database

This build has NO external Muhurtham API dependency. The database contains a pre-populated 2026-2040 marriage-Muhurtham seed set compiled from published public marriage-muhurtham calendars. 2026 was cross-checked against the Chennai-specific DrikPanchang marriage calendar. Future source tables can differ by Panchang tradition, so KVN Admin can override the ⭐ flag for any date.

The ⭐ flag is independent of booking availability. A website enquiry never changes availability. Only a manager/admin confirmation changes `calendar_dates`.

Sources used for the seed research include DrikPanchang (Chennai for 2026), Astroica marriage-Muhurtham tables, and BirthAstro marriage-Muhurtham tables.
